VecCJK — 矢量 PDF 内嵌中文字体
================================

来源与派生
----------
VecCJK 是 **Noto Sans CJK SC Regular** 的子集字体（SIL Open Font License 1.1），
经以下处理后随本仓库分发：
  1. 从 NotoSansCJK-Regular.ttc 抽取 SC 面（font index 2）；
  2. CFF/OTF 轮廓经 fontTools + cu2qu 转换为 TrueType glyf 轮廓（jsPDF 只认 glyf）；
  3. pyftsubset 子集化到 GB2312 一级常用字（3755 字）+ ASCII + 全角/常用标点（共 3986 字形）。

版权：Copyright 2014-2021 Google LLC. 保留部分权利。
Noto 是 Google LLC 的注册商标（本派生字体已改名 VecCJK，未沿用 Reserved Font Name）。

本字体随「直接下载矢量 PDF」功能内嵌进产物 PDF，并随 Web 应用打包预缓存。
按 OFL-1.1，子集化产物可自由捆绑/嵌入/再分发，无需开源宿主软件；修改（子集）
后的字体须以本许可证分发并保留本声明。子集 TTF 本体（vector-cjk.ttf）与本
许可证文本一并保存在本目录，即满足「修改版可获取」义务。
